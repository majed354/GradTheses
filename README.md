# مِداد — GradTheses

نسخة أولية لفهرس بحوث ورسائل الدراسات العليا بكلية الشريعة والأنظمة بجامعة الطائف.

- **الموقع:** https://gradtheses-taif.netlify.app
- فهرس عام، بحث عربي، مرشحات، عرض بطاقات وجدول، وصفحة مستقلة لكل عمل.
- مسار قراءة جامعية باستخدام Microsoft Entra OIDC، ثم فتح القارئ المحمي في SharePoint.
- **الوضع المنشور أولًا: بيانات توضيحية فقط، والقراءة مغلقة حتى إعداد الجامعة واختبارها.**
- «مداد» اسم مقترح، وليس هوية رسمية معتمدة. جميع بيانات العينة وأسماء الباحثين والأقسام توضيحية.

## التشغيل

```sh
npm ci
cp .env.example .env.local
npm run dev
```

```sh
npm run check
npm run build
```

Node.js 24، Next.js App Router، TypeScript، openid-client، jose. الخط العربي محلي ضمن الحزمة؛ لا يعتمد تحميله على Google Fonts. النشر على Netlify عبر OpenNext بدون تثبيت محول قديم.

## الربط الجامعي

اقرأ [دليل SharePoint وEntra بالعربية](docs/SHAREPOINT-SETUP.ar.md) و[ملاحظات التشغيل والتحقق](docs/OPERATIONS.ar.md).

متغيرات الإعداد موثقة في [.env.example](.env.example). تبقى الأسرار في Netlify/`.env.local` فقط. لا تضف بادئة `NEXT_PUBLIC_` إليها.

`CATALOG_SOURCE=demo` يعرض العينة. `CATALOG_SOURCE=sharepoint` يقرأ قائمة البيانات المعتمدة عبر Graph؛ أي خطأ ينتج فهرسًا غير متاح ولا يعيد بيانات تجريبية بصمت. `READING_ENABLED=true` لا يضبط سياسة SharePoint؛ هو مفتاح تشغيل بعد التحقق منها. يظل النص المؤجل أو غير المكتمل مغلقًا.

## حدود النسخة

- تحرير البيانات واعتمادها يجريان حاليًا في SharePoint؛ لا توجد لوحة إيداع أو إدارة مخصصة داخل الموقع.
- لا تُخزّن ملفات الرسائل في GitHub أو Netlify، ولا يوجد مسار API يمرر PDF.
- المنصة لا تتحقق برمجيًا من تفعيل سياسة منع التنزيل؛ يجب اختبارها وتوثيقها إداريًا قبل التفعيل.
- تمنع الجلسة غير المخولة من استلام رابط القراءة، ويطبق SharePoint الصلاحيات مجددًا عند فتح الملف.
- مراجعة الدور داخل جلسة المنصة تعتمد على آخر دخول (بحد أقصى ساعة)؛ يجب سحب صلاحية الملف أيضًا عند الإلغاء العاجل.
- لا تدّعي المنصة منع تصوير الصفحات أو إعادة إنتاج المحتوى المرئي.
- موصل الفهرس الأولي يجلب حتى 10,000 سجل على دفعات، ثم يبحث المتصفح في الحقول العامة. قبل تجاوز هذا الحجم أو زيادة الضغط، يلزم بحث وترقيم صفحات من الخادم أو فهرس بحث معتمد.

## المسارات

`/`، `/catalog`، `/theses/[id]`، `/read/[id]`، `/account`، `/access`، `/setup`.

`/api/catalog` يعيد الحقول العامة فقط. `/api/read/[id]` يتحقق من الجلسة وحالة السجل ثم يعيد توجيهًا إلى مضيف SharePoint المحدد. مسارات المصادقة: `/auth/login` و`/auth/callback` و`POST /auth/logout`.
