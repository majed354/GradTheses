# مداد كلية الشريعة والأنظمة — GradTheses

نسخة أولية لفهرس بحوث ورسائل الدراسات العليا بكلية الشريعة والأنظمة بجامعة الطائف.

- **الموقع:** https://gradtheses-taif.netlify.app
- فهرس عام، بحث عربي، مرشحات، عرض بطاقات وجدول، وصفحة مستقلة لكل عمل.
- قراءة باستخدام دخول SharePoint الجامعي القائم؛ لا يحتاج المسار المختار تسجيل تطبيق جديد في Entra.
- 509 سجلات أولية من سجل الإشراف، بسنوات هجرية ومعرّفات ثابتة. تُضاف الملفات تدريجيًا بعد اعتمادها واختبار منع التنزيل.
- اسم المنصة «مداد كلية الشريعة والأنظمة». المعاينات تستخدم عينة توضيحية منفصلة.

## التشغيل

```sh
npm ci
cp .env.example .env.local
npm run dev
```

```sh
npm run check
npm run build
```

Node.js 24، Next.js App Router، TypeScript، openid-client، jose. الخط العربي محلي ضمن الحزمة؛ لا يعتمد تحميله على Google Fonts. النشر على Netlify عبر OpenNext بدون تثبيت محول قديم.

## الربط الجامعي

اقرأ [دليل التشغيل عبر SharePoint القائم](docs/NATIVE-SHAREPOINT.ar.md)، و[جلب ملفات القناة](docs/TELEGRAM-INTAKE.ar.md)، و[ملاحظات التشغيل والتحقق](docs/OPERATIONS.ar.md). يوجد [مسار Entra/Graph اختياري](docs/SHAREPOINT-SETUP.ar.md) للمستقبل.

متغيرات الإعداد موثقة في [.env.example](.env.example). تبقى الأسرار في Netlify/`.env.local` فقط. لا تضف بادئة `NEXT_PUBLIC_` إليها.

`CATALOG_SOURCE=published` يقرأ نسخة البيانات المعتمدة من Netlify Blobs مع تاريخ نشر ظاهر، و`READING_AUTH_MODE=sharepoint` يفتح الروابط المعتمدة في قارئ الجامعة. تحديث القائمة يتبعه نشر يدوي مضبوط؛ لا توجد مزامنة لحظية. `demo` يعرض العينة، و`sharepoint` يشغّل موصل Graph الاختياري. الأخطاء تغلق الفهرس دون عينة بديلة.

`READING_ENABLED=true` لا يضبط سياسة SharePoint؛ هو مفتاح تشغيل بعد التحقق منها. يظل النص المؤجل أو غير المكتمل أو غير المتوفر مغلقًا. يرفض نشر رابط قراءة في المسار المختار دون `DownloadBlocked=true` بعد اختبار الحماية.

## حدود النسخة

- تحرير البيانات واعتمادها يجريان حاليًا في SharePoint؛ لا توجد لوحة إيداع أو إدارة مخصصة داخل الموقع.
- لا تُخزّن ملفات الرسائل في GitHub أو Netlify، ولا يوجد مسار API يمرر PDF.
- المنصة لا تتحقق برمجيًا من تفعيل سياسة منع التنزيل؛ يجب اختبارها وتوثيقها إداريًا قبل التفعيل.
- في المسار المختار، يتحقق SharePoint من دخول القارئ وصلاحياته عند فتح الملف. لا يُعامل رابط التحويل كبديل لحماية الملف، ولا تُنشأ جلسة جامعية داخل نتلفاي.
- مسار Entra الاختياري يتحقق من المستأجر والدور ومدة الجلسة، لكنه غير مطلوب لتشغيل القراءة الأصلية.
- لا تدّعي المنصة منع تصوير الصفحات أو إعادة إنتاج المحتوى المرئي.
- موصل الفهرس الأولي يجلب حتى 10,000 سجل على دفعات، ثم يبحث المتصفح في الحقول العامة. قبل تجاوز هذا الحجم أو زيادة الضغط، يلزم بحث وترقيم صفحات من الخادم أو فهرس بحث معتمد.

## المسارات

`/`، `/catalog`، `/theses/[id]`، `/read/[id]`، `/account`، `/access`، `/setup`.

`/api/catalog` يعيد الحقول العامة فقط. `/api/read/[id]` يتحقق من حالة السجل والرابط المعتمد، ثم يحوّل إلى SharePoint ليتحقق من حساب الجامعة. مسارات Entra الاختيارية: `/auth/login` و`/auth/callback` و`POST /auth/logout`.
