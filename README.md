# مداد كلية الشريعة والأنظمة — GradTheses

منصة لفهرسة بحوث ورسائل الدراسات العليا بكلية الشريعة والأنظمة بجامعة الطائف.

- **الموقع:** [مداد كلية الشريعة والأنظمة](https://gradtheses-taif.netlify.app).
- فهرس عام يضم **521 سجلًا**، مع بحث عربي ومرشحات وبطاقات وجدول وصفحة مستقلة لكل عمل.
- الإتاحة الحالية للبيانات والتوصيفات التحريرية فقط؛ **النصوص الكاملة موقوفة** إلى حين التحقق من أساس إتاحتها وحقوق نشرها.
- أُعدّ **36 ملخصًا تعريفيًا بصياغة أصلية من إعداد المنصة**، وخضعت كل دفعة لمراجعة مستقلة. ليست نسخًا من ملخصات المؤلفين ولا تُنسب صياغتها إليهم.
- تضم الملفات المعالجة 34 مشروعًا بحثيًا للماجستير، وبحثًا تكميليًا للماجستير، وعمل ماجستير لم يوثق نوعه في النسخة؛ منها 35 نسخة مكتملة ونسخة جزئية موصوفة بحدودها.
- تميّز المرشحات بين الدرجة ونوع العمل الموثق، وتُبقي أنواع الأعمال غير المثبتة في السجلات القديمة غير موثقة. لا تُستنتج «رسالة» من الدرجة وحدها.
- تستخدم المعاينات عينة توضيحية منفصلة عن بيانات الإنتاج.

## التشغيل

```sh
npm ci
cp .env.example .env.local
npm run dev
```

```sh
npm run check
npm run build
```

Node.js 24، Next.js App Router، TypeScript، openid-client، jose. الخط العربي محلي ضمن الحزمة؛ لا يعتمد تحميله على Google Fonts. النشر على Netlify عبر OpenNext.

## البيانات والربط الجامعي

اقرأ [دليل SharePoint والنشر](docs/NATIVE-SHAREPOINT.ar.md)، و[سير عمل التوصيف والمراجعة](docs/EDITORIAL-WORKFLOW.ar.md)، و[ملاحظات التشغيل والتحقق](docs/OPERATIONS.ar.md). ويوثق [جلب ملفات القناة](docs/TELEGRAM-INTAKE.ar.md) مسار الاستلام السابق. يوجد [مسار Entra/Graph اختياري](docs/SHAREPOINT-SETUP.ar.md) للمستقبل.

إعداد الإنتاج الحالي:

```dotenv
CATALOG_SOURCE=published
READING_AUTH_MODE=sharepoint
READING_ENABLED=false
SHAREPOINT_READING_HOST=taifedusa.sharepoint.com
```

كل سجلات نسخة النشر الحالية تستخدم `AccessLevel=metadata` وتخلو من `ReadingUrl`. يقرأ `published` نسخة البيانات المعتمدة من Netlify Blobs مع تاريخ نشر ظاهر. التحديث يدوي مضبوط، وليس مزامنة لحظية مع القائمة. يُوقف الخطأ عرض البيانات دون استبدالها بعينة توضيحية. متغيرات الإعداد موثقة في [.env.example](.env.example)، وتبقى الأسرار في إعدادات Netlify أو `.env.local` فقط.

تُحفظ ملفات الرسائل وأصولها في خدمات الجامعة، ولا تُخزن في GitHub أو Netlify. ملفات المطابقة والأدلة ونسخ JSON الخاصة تحت `artifacts/` مهملة في Git. يحتوي مخزن Netlify الخاص على نسخة بيانات مضبوطة الحقول، ولا يحتوي ملفات PDF.

## حدود النسخة

- لا توجد لوحة إيداع عامة أو استمارة رفع مجهولة؛ أُجّل الإيداع العام بطلب صاحب المشروع.
- لا يمرر أي مسار API محتوى PDF. يعيد `/api/catalog` الحقول العامة فقط، ويغلق `READING_ENABLED=false` مسار `/api/read/[id]`.
- وقف القراءة داخل المنصة لا يثبت إلغاء صلاحيات أو روابط سابقة في SharePoint؛ يتحقق ذلك بصورة مستقلة داخل خدمة الجامعة.
- يتطلب أي تفعيل مستقبلي للنص الكامل تحققًا موثقًا من حقوق الإتاحة، ثم مراجعة صلاحيات SharePoint واختبارها بحساب قارئ عادي. منع التنزيل لا ينشئ إذن نشر.
- للمحتوى الموثق فقط توصيف يستند إلى القراءة؛ السجل الذي لا يتوفر نصه يبقى ببياناته، دون اختلاق ملخص من العنوان.
- يجلب الموصل حتى 10,000 سجل على دفعات، ثم يبحث المتصفح في الحقول العامة. عند التوسع يلزم بحث وترقيم صفحات من الخادم أو فهرس بحث معتمد.

## المسارات

`/`، `/catalog`، `/theses/[id]`، `/read/[id]`، `/account`، `/access`، `/setup`.

البحث يستخدم `degree` للدرجة و`kind` لنوع العمل الموثق، إضافة إلى بقية المرشحات. مسارات Entra الاختيارية موجودة للمستقبل، ولا يُحتاج إليها لتصفح الفهرس والتوصيفات العامة.
