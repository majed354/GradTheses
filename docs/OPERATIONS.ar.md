# تشغيل النسخة الأولية

## النشر

المستودع `majed354/GradTheses` والفرع الإنتاجي `main`. Netlify ينفذ `npm run build` وينشر `.next` عبر OpenNext. تراجع حالة الربط الفعلية من لوحة Continuous deployment. مجلد `.netlify` محلي ومهمل في Git.

الموقع العام: https://gradtheses-taif.netlify.app

الفهرس عام. المسار المختار يستخدم دخول SharePoint الجامعي القائم كما في [دليل التشغيل](NATIVE-SHAREPOINT.ar.md). Entra/Graph داخل التطبيق مسار اختياري غير مفعّل.

## حالات التشغيل

- `demo`: ثمانية سجلات مصطنعة، وتحذير واضح، ولا قراءة لملفات.
- `published`: نسخة بيانات معتمدة في Netlify Blobs، مع تاريخ نشر ظاهر. القراءة الأصلية عبر SharePoint تتطلب رابطًا جرى اختباره مع منع التنزيل. التحديث يدوي مضبوط، لا مزامنة لحظية مع القائمة.
- `sharepoint` مع القراءة مغلقة: فهرس حقيقي من القائمة، ومسار القراءة يوضح أنه قيد التجهيز.
- `sharepoint` مع القراءة مفعلة: يحتاج إعداد Entra كاملًا، ودور قارئ، ورابطًا معتمدًا، وصلاحيات ملف في SharePoint.
- قيمة مصدر غير معروفة أو خطأ Graph: فشل مغلق دون بيانات بديلة.

## الحماية

- لا يوجد PDF في المستودع أو بيانات جلسة حساسة داخل حزمة المتصفح.
- في مسار Entra الاختياري، Cookies مشفرة ومقيدة بالغرض والمدة. تحقق OIDC يشمل state وnonce وPKCE والتوقيع والمستأجر والدور. أما المسار المختار فيستخدم جلسة SharePoint داخل خدمة الجامعة.
- روابط العودة محصورة في `/read/{id}`؛ رابط القارئ محصور في مضيف SharePoint مضبوط بالخادم.
- `/api/read` لا يعيد محتوى الملف ولا يحصل على صلاحيات مكتبة الرسائل.
- سجلّات الأخطاء عامة ولا تطبع الأسرار أو رد Graph الخام أو روابط القراءة.
- الردود التي تتضمن جلسة أو تحويلًا للقارئ غير مخزنة؛ الفهرس لا يخزن من جهة الخادم في هذه النسخة لتسهيل السحب الفوري.
- SharePoint هو حاجز الوصول الحاسم عند السحب العاجل. في مسار Entra الاختياري فقط، قد يبقى الدور داخل جلسة المنصة حتى انتهائها (ساعة كحد أقصى).
- CSP الحالي يسمح inline scripts لتشغيل Next.js؛ تشديده باستخدام nonces وتحليل متطلبات التشغيل خطوة لاحقة عند التوسع.

## حدود التحقق

تُختبر محليًا: البحث، تنقية السجلات، حجب الروابط الداخلية، صلاحيات الدور، منع التحويل الخارجي، وتلاعب الجلسة وانتهاؤها. تُراجع الواجهة بالجوال وسطح المكتب، وتُفحص مسارات النسخة المنشورة.

لا يوصف منع تنزيل PDF أو وصول القارئ الجامعي بأنهما مفعّلان أو مجرّبان قبل اختبار ملف فعلي بحساب قارئ عادي. تظل الملفات غير المعتمدة على بيانات الموضوع فقط.

## النمو

يجلب الموصل 200 سجل لكل دفعة، بحد أقصى 50 دفعة، ويبحث المتصفح في الحقول العامة. للمجموعات الكبيرة، يلزم الانتقال إلى بحث خادمي مفهرس وترقيم صفحات، مع إعادة التحقق من عتبات SharePoint وتحديد حمل الاستخدام. لا يتضمن الإصدار بحثًا في النص الكامل أو إيداعًا ذاتيًا أو أتمتة موافقات.
